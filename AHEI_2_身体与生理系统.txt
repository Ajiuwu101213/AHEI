8.1 伤害类型总览（七类伤害）

    AHEI的身体会因以下七类物理/化学作用而受伤，每一类有不同的致伤原理
   （详见文档7第四章）和不同的生理后果、恢复时间（详见本章）。

| 伤害类型 | 致伤原理 | 关键判定参数 | 典型场景 |
|---------|---------|------------|---------|
| 冲击伤 | 钝器碰撞，面积较大，压强较低 | 碰撞力 ÷ 接触面积 = 压强 | 被棍棒击打、被石头砸中、被同类拳击 |
| 重力伤 | 从高处坠落，动能转化为冲击 | 落地速度 × 体重 ÷ 接触面积 | 从悬崖坠落、从树上摔下 |
| 压力伤 | 被重物持续挤压 | 重物质量 × 9.8 ÷ 接触面积 | 被倒塌的树木压住、被巨石碾压 |
| 贯穿伤 | 尖锐物体刺入身体 | 刃口压强 > 皮肤抗压强度 | 被矛刺中、被箭射中、被兽牙咬穿 |
| 割裂伤 | 刀刃切过软组织 | 刃口压强 > 组织抗压强度 | 被石刀割伤、被斧刃劈中 |
| 温度伤 | 极端温度破坏细胞 | 温度 > 45°C 或 < 0°C | 被火烧伤、冻伤 |
| 化学伤 | 腐蚀性物质破坏组织 | 物质腐蚀性参数 | 被酸液溅到、被碱液灼伤 |

8.2 各部位骨骼断裂阈值表

    每个身体部位有独立的bone_integrity值（0-1），初始值为1.0（完整）。
    当碰撞力超过该部位的断裂阈值时，发生骨折。

| 部位 | force_multiplier | 断裂阈值(N) | 骨折后果 |
|------|-----------------|------------|---------|
| 头骨 | 2.5 | 75 | 认知能力下降，视觉模糊，可能昏迷 |
| 肋骨 | 1.5 | 45 | 呼吸时持续微痛，体力恢复速度降低30% |
| 上臂骨 | 1.0 | 30 | 该臂丧失抓取和攻击能力 |
| 前臂骨 | 0.8 | 24 | 该臂部分功能丧失 |
| 大腿骨 | 1.5 | 45 | 移动速度减半，需单腿跳跃 |
| 小腿骨 | 1.2 | 36 | 移动速度降低40% |
| 手指骨 | 0.3 | 9 | 该手指无法使用 |
| 脊柱 | 2.0 | 60 | 下半身瘫痪（永久），移动功能完全丧失 |

8.3 骨折判定与后果

    判定条件：施加力 > fracture_threshold（默认30N）× force_multiplier

    Godot端实现：
    ```gdscript
    func check_fracture(part_name: String, impact_force: float) -> bool:
        var multiplier = BONE_FRACTURE_MULTIPLIERS.get(part_name, 1.0)
        var threshold = FRACTURE_BASE_THRESHOLD * multiplier
        if impact_force > threshold:
            bone_integrity[part_name] = 0.0  # 骨折
            _apply_fracture_consequences(part_name)
            return true
        return false
    
    func _apply_fracture_consequences(part_name: String) -> void:
        match part_name:
            "head":
                cognitive_penalty = 0.3  # 认知下降30%
                vision_blur = true
            "spine":
                lower_body_paralysis = true  # 下半身瘫痪
            "l_arm", "r_arm":
                arm_disabled[part_name] = true
            "l_leg", "r_leg":
                move_speed_multiplier = 0.5 if part_name in ["l_leg","r_leg"] else 0.6
            "ribs":
                stamina_recovery_multiplier = 0.7
    ```

    骨折恢复：骨折恢复极慢（详见8.5节恢复时间总表），恢复速度受年龄、营养、医疗处理影响。

8.4 贯穿伤与割裂伤的流血机制

    贯穿伤和深层割裂伤会导致持续流血：

    流血等级：
        - 轻微流血（浅层割伤、毛细血管破裂）：每秒扣0.2 health，持续30-60秒后自动凝固
        - 中度流血（深层割伤、浅层贯穿）：每秒扣0.5-1 health，需包扎止血
        - 严重流血（动脉破裂、深层贯穿）：每秒扣2-5 health，60秒内可致死，必须立即包扎

    止血方式：
        - 徒手按压伤口：流血速率减半
        - 用清洁布/兽皮包扎：流血速率降至25%
        - 用药草糊敷伤口：流血速率降至25%，恢复速度额外+30%
        - 用火烙伤口（极端手段）：立即止血，但造成额外烧伤伤害（一级烧伤）

    失血过多的后果：
        - 失血量 > 20%（约13秒严重流血）：体力消耗加快，行动迟缓
        - 失血量 > 40%（约26秒严重流血）：意识模糊，视觉模糊，认知扣减
        - 失血量 > 60%（约40秒严重流血）：昏迷，高概率死亡

    Godot端向Python端上报流血事件：
    ```json
    {"type":"event","ahei_id":"A001","event":"bleeding","severity":"severe","bleed_rate":3.0}
    ```

8.6 恢复速度的修正因素

    所有恢复过程的实际速度由以下因素综合决定：

    - healing_rate基因：默认1.0，范围0.5-1.5（可遗传）
    - 年龄系数：年轻恢复快（1.5x），成年正常（1.0x），老年恢复慢（0.5x）
    - 营养状态：energy > 50时正常恢复（1.0x），30-50时恢复减半（0.5x），
                < 30时恢复大幅减慢（0.25x），< 10时几乎不恢复（0.05x）
    - 医疗处理：用药草包扎→恢复速度+30%（1.3x）
                用夹板固定骨折→恢复速度+20%（1.2x）
                无任何处理→基础恢复速度（1.0x）
    - 睡眠加成：睡眠期间恢复速度加倍（2.0x）
    - 自主神经模式：副交感模式（休息/消化）下恢复速度+50%（1.5x）

    计算公式：
        实际恢复时间 = 基础恢复时间 / (healing_rate × 年龄系数 × 营养系数 × 医疗系数 × 睡眠加成 × 自主神经加成)

    示例：一个healing_rate=1.2的年轻AHEI（年龄系数1.5），在energy=60（营养1.0）时，
          用药草包扎（医疗1.3）并在夜晚睡眠（睡眠2.0），其恢复速度是默认的
          1.2 × 1.5 × 1.0 × 1.3 × 2.0 = 4.68倍。一处需要10天恢复的割伤，
          实际只需约2.1天即可痊愈。

8.7 死亡条件总汇表

| 死亡原因 | 判定条件 | 是否可避免 |
|---------|---------|-----------|
| 饥饿死亡 | energy归零且持续30秒未进食 | 是，及时进食 |
| 外伤死亡 | health归零（任何外伤累积） | 是，及时治疗 |
| 失血死亡 | 失血量 > 60%（约40秒严重流血未止血） | 是，及时止血包扎 |
| 中毒死亡 | toxin_level持续过高无法代谢 | 是，服用解毒草药或强免疫力 |
| 溺水死亡 | 水下窒息超过90秒 | 是，及时浮出水面 |
| 高温死亡 | 体温 > 42°C持续过久 | 是，及时降温 |
| 低温死亡 | 体温 < 30°C持续过久 | 是，及时取暖 |
| 坠落死亡 | 从>20米坠落（头着地则>5米即可致命） | 是，避免高处坠落 |
| 衰老死亡 | 达到lifespan_max（默认36000秒=10游戏小时） | 否（除非被设置为不衰老） |
| 疾病死亡 | 感染未被免疫系统击败 | 是，提高免疫力或用药 |
| 窒息死亡 | 缺氧环境（洞穴深处/密闭空间） | 是，及时离开缺氧区域 |
| 挤压死亡 | 被极重物体持续挤压>5分钟 | 是，移开重物或逃脱 |

8.8 温度伤的详细分级

    烧伤等级（接触火焰或高温物体）：

| 等级 | 温度范围 | 表现 | health扣减 | 恢复时间 |
|------|---------|------|-----------|---------|
| 一级 | 45-55°C | 局部变红，疼痛 | -5 | 1-2天 |
| 二级 | 55-70°C | 起水泡，剧痛 | -15 | 5-10天，可能留疤 |
| 三级 | >70°C | 组织坏死，焦黑 | -30 | 永久疤痕，功能永久受损 |

    冻伤等级（接触极低温或长时间处于严寒）：

| 等级 | 温度范围 | 表现 | health扣减 | 恢复时间 |
|------|---------|------|-----------|---------|
| 一级 | 0°C ~ -10°C | 局部麻木，皮肤发红 | -3 | 1-2天 |
| 二级 | -10°C ~ -25°C | 起水泡，皮肤发紫 | -10 | 5-10天 |
| 三级 | <-25°C | 组织冻结坏死，变黑 | -25 | 永久损伤，可能需截肢 |

8.9 坠落高度与伤害对照表

    以70kg体重的AHEI为例：

| 坠落高度 | 落地速度 | 冲击力 | 可能后果 |
|---------|---------|--------|---------|
| <2米 | <6.3 m/s | <8,800 N | 轻微淤伤或无伤 |
| 2-5米 | 6.3-10 m/s | 8,800-14,000 N | 腿骨可能骨折，软组织挫伤 |
| 5-10米 | 10-14 m/s | 14,000-19,600 N | 腿部严重骨折，可能脊柱损伤 |
| 10-20米 | 14-20 m/s | 19,600-28,000 N | 多处骨折，高概率死亡 |
| >20米 | >20 m/s | >28,000 N | 几乎必定死亡 |

    注：如果头部着地（在坠落过程中随机判定，概率约15%），伤害翻倍，
    5米以上的头着地坠落即可能致命。

8.10 挤压时间与伤害对照表

| 持续时间 | 伤害 | health扣减 |
|---------|------|-----------|
| <10秒 | 轻微淤伤 | -1~3 |
| 10-30秒 | 软组织挫伤 | -5~10 |
| 30-60秒 | 肌肉坏死开始 | 每秒-0.5 health |
| 1-5分钟 | 骨骼可能断裂 | 被压部位功能永久受损 |
| >5分钟 | 被压部位可能需截肢 | 高概率死亡 |

8.11 模组扩展接口

    所有伤害类型的判定参数、恢复时间、死亡条件均可通过模组注册表自定义。
    
    模组可以：
        - 新增伤害类型（如“辐射伤”），定义其判定条件和恢复参数
        - 修改骨骼断裂阈值（如降低头骨阈值使头部更脆弱）
        - 添加新的医疗物品（如更强效的药草，恢复速度+50%）
        - 添加新的死亡条件（如“辐射致死”）
        - 修改特定物种的恢复速度基因默认值

    注册表示例：
    ```gdscript
    # 模组中注册自定义医疗物品
    api.register_item("advanced_poultice", {
        "name": "高级药膏",
        "healing_bonus": 0.5,  # 恢复速度+50%
        "stops_bleeding": true,
        "duration": 300  # 持续300秒
    })
    ```
