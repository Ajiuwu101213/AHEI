## 一、这是什么？

AHEI是一个**数字生命演化实验平台**，不是一个传统游戏或聊天AI。

我在电脑里创造了一个由程序生成的物理世界——有山、有河、有矿脉、有森林。然后我放进去几百个什么都不懂的“数字小人”，它们不知道火是什么，不知道石头能打火，不知道铜和锡混在一起烧能炼出更硬的东西。

我只给了它们最基本的东西：
- 一幅有物理属性的身体
- 一个会饿、会疼的生理系统
- 一个会预测的大脑

**没有任何预设知识，没有任何配方，没有元素周期表。** 我不干预它们。我只是静静观察，看它们能从最原始的生存本能里，长出什么东西来。


## 二、技术架构

### 引擎与语言
- **3D引擎**：Godot 4.x（负责渲染、物理、交互）
- **AI后端**：Python + PyTorch（预测编码神经网络）
- **通信**：WebSocket（JSON协议，连接Godot与Python端）
- **存档**：独立世界文件夹架构（类似《我的世界》的存档方式）

### 六层系统架构
1. **物理世界层**：程序化地形、动态气候、物理碰撞
2. **身体硬件层**：基因驱动的程序化身体，包含关节、器官
3. **感官接口层**：视觉（射线检测）、听觉（声波衰减）、触觉（碰撞信号）、嗅觉、味觉 → 60维感官向量
4. **神经网络大脑层**：预测编码核心网络，接收感官输入，输出行为
5. **学习与演化层**：遗传算法管理种群，DNA重组、变异、自然选择
6. **观察与记录层**：自由摄像机、全知面板、日志回放系统

### 核心认知模型
- **预测编码**：大脑不断预测下一刻的感官输入，预测与实际之间的误差是所有学习和情绪的计算源头
- **内稳态驱动**：饥饿、疼痛不是标签，是生理变量的波动强制劫持决策过程
- **多巴胺系统**：计算实际奖励与预期奖励的差异
- **血清素系统**：调控长期社会情绪和地位感知


## 三、核心设计原则（铁律）

1. **无预设知识**：没有合成表，没有技能树，没有元素周期表。一切靠试错和演化
2. **内生稳态驱动**：行为的根本动力是维持生理平衡，不是外部指令
3. **万物皆物理**：所有物体有密度、硬度、弹性，伤害由压强公式（F/A）计算
4. **感官局部性**：AHEI没有上帝视角，视觉会被遮挡，听觉会被遮蔽
5. **情感涌现**：恐惧、好奇、愧疚不是写死的标签，是从预测误差中计算出来的
6. **知识涌现**：冶炼配方、合金工艺不是代码预设，是AHEI与物理世界交互后的生存经验


## 四、实验目标

观察在一个物理规则完整但没有任何预设知识的世界里，一群由内生稳态驱动的智能体，能否自主涌现出：
- 工具使用与制造
- 语言符号与社会交流
- 部落与领地
- 冶炼技术与文明发展
- 以及对“意识能否以非人类形态自然涌现”这个终极问题的启示
