1.1 情感的本质（无预设标签的涌现）

    AHEI的情感不是代码中写死的标签。代码中永不出现 feeling = "hungry"
    或 feeling = "sad"。所有情感都是从预测编码、多巴胺、血清素、
    镜像神经元、自主神经等基础系统的组合状态中自然涌现的。

    一种情感对应一组特定的系统状态组合：
        - 预测误差水平
        - 多巴胺水平（相对基线）
        - 血清素水平
        - 自主神经模式（交感/副交感）
        - 镜像神经元激活程度
        - 催产素水平

    这些状态全部由Python端的大脑服务器计算，通过WebSocket推送给Godot端。
    Godot端的EmotionController.gd根据收到的状态数据，控制3D角色的材质、
    姿态和动画表现。

1.2 基本情感

    饥饿：
        触发：energy < STARVATION_THRESHOLD（默认20）
        系统状态：预测误差持续偏高（能量预测与实际不符）
                 多巴胺低于基线（当前状态不如预期）
                 觅食行为优先级被强制拉到最高
        外部表现：减少社交和探索，专注寻找食物
        如果持续饥饿不进食→health扣减→最终死亡
        Godot表现：觅食行为权重提升（由Python端行为选择器控制），
                 社交和探索动画频率降低

    恐惧：
        触发：预测误差突然飙升（如检测到捕食者、突发巨响）
        系统状态：交感神经强制激活
                 多巴胺骤降
                 逃跑或僵直行为被触发
                 其他行为被压制
        外部表现：瞳孔放大、心跳加速、身体僵直或转身逃跑
        功能：保护生命免受威胁
        Godot表现：
            - 瞳孔放大：虹膜节点scale×1.3（由EmotionController控制）
            - 心跳加速：通过触觉传感器的频率反馈模拟
            - 身体僵直或转身逃跑：由Python端行动指令驱动
            - 体色变浅：skin_material.albedo_color亮度+0.2

    满足：
        触发：进食后energy回升到舒适水平，或完成重要任务
        系统状态：预测误差归零
                 多巴胺回到基线
                 副交感神经接管
        外部表现：放松姿态、愿意社交、愿意休息
        Godot表现：
            - 放松姿态：活动频率降低
            - 社交意愿增强：主动接近其他个体
            - 休息倾向增加

    愤怒：
        触发：预测被暴力打破（食物被抢、伴侣被夺、领地入侵）
        系统状态：预测误差激增
                 攻击行为模块被激活
                 多巴胺骤降（预期拥有→实际失去）
        外部表现：体色变深、发出威胁声、冲向入侵者
        Godot表现：
            - 体色变深：skin_material.albedo_color亮度-0.2
            - 威胁声：VocalSynthesizer触发threat模式，播放低频拉长声音
            - 冲向入侵者：由Python端行动指令驱动

    好奇：
        触发：中等程度的预测误差（环境不完全可预测，但无明显威胁）
        系统状态：预测误差适中→驱动探索行为以减少误差
                 多巴胺微升（新信息本身就是奖励）
        外部表现：走向未知区域、观察陌物体、试探性触碰
        Godot表现：
            - 头部转向未知物体：Neck关节微调rotation
            - 身体倾向探测方向
            - 探索行为权重提升

    不知所措：
        触发：所有已知行动选项的预期奖励都低于阈值
              或面临完全陌生的情境
        系统状态：多个信号相互冲突，无行动能胜出
                 行为输出的竞争陷入僵局
        外部表现：呆站原地、来回转头、身体微晃
        功能：系统在等待更多信息或等待某个行动选项突破阈值
        Godot表现：
            - 呆站：movement暂停
            - 来回转头：Head节点周期性rotation微调
            - 身体微晃：极小幅度的随机位移

    紧张：
        触发：面临重要的社会评价场景（求偶、在部落面前发言）
              或处于高重要性与高不确定性并存的情境
        系统状态：交感神经激活
                 运动指令被噪声干扰
        外部表现：手部微颤、声音变高变抖、动作不自然、出汗
        Godot表现：
            - 手部微颤：手掌节点的rotation添加随机微小抖动
            - 声音变高变抖：VocalSynthesizer的base_frequency临时上调+频率调制
            - 动作不自然：motor_joint的stiffness临时降低，导致动作不稳
            - 出汗：皮肤材质roughness临时微降0.05

1.3 复杂社会情感

    愧疚：
        触发：观察到因自己的行为而受伤的同类
        系统状态：镜像神经元激活（感知对方的痛苦）
                 因果归因系统将对方的痛苦与自己的行为链接
                 多巴胺骤降（预期"我做了正确的事"→实际"我造成了伤害"）
        外部表现：回避受害者、或主动接近补偿（提供食物、帮助）
        功能：修复被自己破坏的社会关系

    怀旧：
        触发：环境线索激活了过去的长期记忆
              记忆中的状态比当前更好
        系统状态：多巴胺预测"回到那个状态会很幸福"
                 但实际上无法回去→多巴胺骤降
        外部表现：停止当前行动、望向远方、发出长低频声音
        功能：驱动回到过去有益环境的本能（尽管往往无法实现）

    嫉妒：
        触发：预测某资源（伴侣/领地/地位）属于自己
              第三者出现打破预测
        系统状态：预测误差激增
                 攻击行为模块被激活
        外部表现：攻击第三者、或试图展示更强能力以赢回资源
        功能：保护自己的资源不被夺走

    吃醋：
        触发：依恋对象与另一个体互动（注意力转移）
        系统状态：催产素因"可能失去依恋对象"的预测而下降
                 交配机会预测值下降
        外部表现：重新靠近伴侣、试图用身体挡住第三者的视线
        功能：维护已有的亲密关系

    心动：
        触发：视觉输入远超过预期（看到极具吸引力的异性）
        系统状态：多巴胺大幅正向爆发
                 注意力完全锁定在对方身上
        外部表现：呆站、盯着对方看、可能忘记正在做的事
        功能：启动求偶行为的触发器

    害羞：
        触发：发现自己被多个同类注视
              对当前行为的评价高度不确定
        系统状态：血清素暂时下降（社会不确定性）
                 回避行为被激活
        外部表现：体色微红（如果外观系统支持）、低头、转身走开
        功能：避免因行为失当而在社会评价中受损
        Godot表现：
            - 体色微红：面部顶点颜色叠加粉色（见文档2皮肤材质章节）
            - 低头：Neck关节的MotorJoint.set_target(15.0)
            - 转身走开：由Python端行为指令驱动

    骄傲：
        触发：自己完成的行为远超预期
              且有旁观者在场见证了该行为
        系统状态：多巴胺大幅正向爆发
                 社会地位感知提升
        外部表现：身体挺直、步伐变大、可能会展示成果
        功能：巩固社会地位
        Godot表现：
            - 身体挺直：躯干节点的scale.y微调（模拟挺胸）
            - 步伐变大：步行动画的步幅参数+20%

    羞耻：
        触发：自己的行为被群体排斥
              "被接纳"的预测被打破
        系统状态：多巴胺骤降
                 血清素下降
        外部表现：低头、回避眼神、远离群体
        功能：学习社会规范，避免被驱逐

    感激：
        触发：其他个体给予远超预期的帮助
        系统状态：多巴胺大幅正向爆发
                 对该个体的催产素水平上升
        外部表现：发出友善声音、给予回赠
        功能：建立互惠合作关系

1.4 情感冲突与行为权衡

    当两个以上情感同时被激活且冲突时:
        例如同时饥饿(能量<20)和恐惧(捕食者在附近)
        两个行为信号互相竞争(觅食 vs 逃跑)
        表现为原地前后移动、犹豫不决
        最终以生理需求紧急程度和社会情境加权决定行为输出

1.5 情感的身体表现

    所有情感都有对应的身体变化:
        恐惧→瞳孔放大、心跳加速、出汗
        愤怒→体色加深、肌肉绷紧、呼吸加快
        害羞→体色微红（如果外观系统支持）、低头
        满足→身体放松、呼吸平稳

1.6 Godot实现要点（EmotionController.gd）

    挂载在AHEI_Body节点上，接收Python端通过WebSocket推送的
    emotion_state消息，控制3D表现。

    ```gdscript
    class_name EmotionController
    extends Node

    @export var ahei_body: Node3D
    @export var iris_l: MeshInstance3D
    @export var iris_r: MeshInstance3D
    @export var skin_material: StandardMaterial3D
    @export var vocal_synthesizer: VocalSynthesizer
    @export var neck_joint: MotorJoint
    @export var hand_l_joint: MotorJoint
    @export var hand_r_joint: MotorJoint

    var current_emotion: String = "neutral"
    var emotion_intensity: float = 0.0

    func update_emotion(emotion_state: Dictionary) -> void:
        current_emotion = emotion_state.get("dominant", "neutral")
        emotion_intensity = emotion_state.get("intensity", 0.0)
        
        match current_emotion:
            "fear": _apply_fear(emotion_intensity)
            "anger": _apply_anger(emotion_intensity)
            "shy": _apply_shy(emotion_intensity)
            "satisfied": _apply_satisfied(emotion_intensity)
            "curious": _apply_curious(emotion_intensity)
            "nervous": _apply_nervous(emotion_intensity)
            "proud": _apply_proud(emotion_intensity)
            _: _apply_neutral()

    func _apply_fear(intensity: float) -> void:
        var iris_mult = 1.0 + intensity * 0.3
        iris_l.scale = Vector3.ONE * iris_mult
        iris_r.scale = Vector3.ONE * iris_mult
        skin_material.albedo_color = skin_material.albedo_color.lightened(intensity * 0.25)

    func _apply_anger(intensity: float) -> void:
        skin_material.albedo_color = skin_material.albedo_color.darkened(intensity * 0.25)
        vocal_synthesizer.set_mode("threat")

    func _apply_shy(intensity: float) -> void:
        _overlay_face_color(Color(1.0, 0.5, 0.5), intensity * 0.3)
        if neck_joint: neck_joint.set_target(15.0 * intensity)

    func _apply_satisfied(intensity: float) -> void:
        pass  # 放松姿态，由行为选择器降低活动频率

    func _apply_curious(intensity: float) -> void:
        if neck_joint: neck_joint.set_target(20.0 * intensity)  # 头部微转

    func _apply_nervous(intensity: float) -> void:
        if hand_l_joint: hand_l_joint.set_target(randf_range(-5, 5) * intensity)
        if hand_r_joint: hand_r_joint.set_target(randf_range(-5, 5) * intensity)
        vocal_synthesizer.set_mode("nervous")  # 频率调制

    func _apply_proud(intensity: float) -> void:
        ahei_body.scale.y = 1.0 + intensity * 0.05  # 挺胸

    func _apply_neutral() -> void: pass
    ```

1.7 伤痛对情感系统的持久影响（本次修订新增）

    当AHEI处于受伤状态时（详见文档2第八章），其情感系统不仅
    在受伤瞬间产生剧烈反应（详见文档3第四章4.7节疼痛闭环），
    而且在伤后恢复期间会经历持续的情感基线扰动。
    这些影响不是预设标签，而是从预测编码、血清素、慢性多巴胺等
    基础系统的持续扰动中自然涌现的。

    【疼痛导致的易怒】
        当AHEI长期处于疼痛状态时（如骨折未愈、慢性感染、
        大面积淤伤），其预测编码网络持续产生中等偏高水平的
        预测误差。这是因为大脑的预测模型持续输出“身体应完好无损”
        的预期，但感官输入持续报告“身体某处有损伤信号”。
        即使AHEI静止不动，损伤部位的触觉传感器仍在每帧
        向大脑发送低强度的疼痛信号。

        这种持续偏高的预测误差使恐惧系统的触发阈值降低。
        原本不会引起恐惧的轻微刺激——如同类靠近时脚步稍重、
        树枝折断的声音、或者只是视野边缘出现的陌生物体——
        现在可能因为预测误差基线已经偏高，
        只需要一个微小的额外扰动就能越过恐惧阈值。

        恐惧反应在行为上表现为防御性攻击——
        受伤的AHEI可能对接近它的同类发出威胁声、
        做出攻击姿态，即使对方并无恶意。
        这就是“受伤后更容易发怒”的涌现机制。
        它不是代码中预设的“受伤=易怒”标签，
        而是预测误差基线偏移 + 恐惧阈值降低的必然结果。

        Python端表现：预测误差基线从正常值0.05-0.1
        上移至0.2-0.3（取决于伤势严重程度），
        恐惧触发阈值从0.4降至0.25。
        受伤越重、疼痛持续时间越长，基线偏移越大。
        个体差异：高神经质个体的阈值下降更显著（约-40%），
                 高宜人性个体的阈值下降较少（约-15%），
                 因为高宜人性个体对社交冲突的抑制力更强。

    【恐惧敏感化（创伤后应激倾向）】
        受过重伤的AHEI对未来可能造成伤害的线索变得极度敏感。
        这是文档3第四章4.7节描述的“长期记忆标记”的直接后果——
        创伤记忆以极高情绪标签（-0.7到-0.95）刻入长期记忆后，
        任何与创伤情境相似的感官线索都能触发侵入性回忆
       （详见文档3第十章10.8节）和强烈的恐惧反应。

        这种“一朝被蛇咬，十年怕井绳”的泛化恐惧，
        在AHEI的日常行为中表现为：
            - 拒绝进入与受伤地点地形相似的环境，
              即使该地形在当前季节是安全的
            - 对与伤害源颜色相似的物体产生过度回避
            - 睡眠质量下降，因为睡眠中大脑回放创伤记忆
            - 在群体中表现为“胆小”或“过度谨慎”

        恐惧敏感化的程度受表观遗传标记影响：
        如果AHEI的fear_generalization标记值较高
       （详见文档3第十八章18.4节），
        其恐惧泛化范围更广——不仅怕伤害过自己的具体物体，
        也怕任何与该物体有一两个共同特征的物体。

        这种泛化恐惧在演化上具有适应性：
        宁可对无害物体过度警惕，也比漏掉一个真正的危险好。
        但当环境变得安全后，过度泛化的恐惧会成为生存负担，
        限制AHEI的探索范围和资源获取能力。

    【长期伤病的情绪基线偏移】
        如果伤痛持续数周以上（如严重骨折、慢性感染），
        AHEI的血清素系统会因以下因素的综合影响而持续偏低：

        第一，社会地位下降（详见第十章10.6节）：
        受伤AHEI在群体中的话语权减少、在食物分配中的优先级降低，
        社会地位的持续下降直接拉低血清素水平。

        第二，觅食能力下降：受伤AHEI无法像健康时那样高效获取食物，
        能量储备长期偏低。能量储备是血清素系统的重要输入参数之一——
        energy<40时，血清素基线自动下调约0.15。

        第三，社交互动减少：受伤AHEI因行动不便和疼痛
        而减少参与集体活动，社交减少意味着来自同伴的
        正向社会信号（如友善的肢体接触、共同觅食的协作感）减少，
        这些信号是血清素的重要正向输入。

        第四，自主神经长期处于交感偏高的状态：
        疼痛信号持续激活交感神经，副交感神经的“休息/恢复”模式
        无法充分发挥作用。这导致血清素的自然恢复受阻。

        持续偏低的血清素（<0.3）在行为上表现为：
            - 情绪低落、兴趣减退、不愿参与社交和探索活动
            - 对原本喜欢的活动（如探索新区域、制作工具）失去动力
            - 睡眠质量下降，入睡困难或易醒
            - 食欲下降，即使有充足食物也吃得比平时少

        如果血清素水平在伤愈后仍未恢复到正常范围，
        可能发展为功能意义上的“慢性抑郁状态”——
        这不是代码预设的疾病标签，
        而是血清素系统长期失衡、且缺乏足够的正向输入
        来重新校准的自然结果。

    【社交退缩的涌现】
        受伤AHEI的社交行为会发生以下可观察的变化：

        第一，减少主动社交发起的频率。
        这是因为疼痛信号持续占据感官处理资源，
        大脑的认知带宽被疼痛大量占用，
        剩余用于处理社交信息的资源不足。
        AHEI不是“不想”社交，而是“没有余裕”去社交。

        第二，对社交信号的反应变得迟钝。
        健康时，同伴的一个友善手势或问候声能在1-2秒内得到回应。
        受伤时，同样的信号可能需要3-5秒才能得到回应，
        甚至完全没有回应。这是因为疼痛信号的优先级高于社交信号，
        大脑的处理队列中疼痛信号排在前面。

        第三，可能独自躲藏在远离部落中心的地方休息。
        这既是物理上的远离（便于安静休养），
        也是社会上的远离（减少与健康个体的比较压力）。

        第四，对其他个体的接近表现出轻微回避。
        这不是恐惧驱动的回避，而是一种“节省能量”的策略——
        每一次社交互动都需要消耗能量，
        受伤AHEI本能地减少非必要的能量支出。

        这种社交退缩在伤愈后会逐渐恢复，
        但如果受伤期间经历了社会排斥（被驱逐或边缘化），
        恢复后的AHEI可能长期保持较低的社交意愿，
        因为其长期记忆中存储了“受伤时被抛弃”的创伤记忆。

    【伤痛情感的代际传递】
        如果某代AHEI种群长期生活在高危险环境中，
        频繁受伤，其表观遗传标记会发生变化。
        详见文档3第十八章18.4节。

        具体到情感层面：
            - 母体在孕期中持续处于疼痛和恐惧状态
              →后代出生时stress_response_base标记升高
              →后代对压力的情感反应更强烈
            - 母体在孕期中反复被多种物体伤害
              →后代fear_generalization标记升高
              →后代对陌生物体的恐惧泛化范围更广

        这种代际传递在演化上的意义是：
        如果母亲生活的环境充满危险，
        后代天生具有更高的警觉性是有利的。
        但如果环境已经变安全了，
        这种代际传递的“创伤敏感化”需要数代时间
       （表观遗传标记的可逆衰减）才能恢复，
        期间种群的行为策略可能过于保守，
        错失探索新资源的机会。

第十章  道德与社会规范
================================================================================

10.1 道德的涌现

    道德不是学来的教条，而是从大脑中自然生长的行为规范:
        观察到受害者痛苦→镜像神经元激活→自己不适→
        下次避免做同样的事→道德内化
        被群体排斥→血清素下降→恐惧→主动遵守规范

10.2 友善与利他

    高宜人性个体的镜像神经元高度敏感，能对同伴痛苦感同身受。
    利他行为的驱动力：帮助他人→消除自己因共情而产生的不适→
    同时也可能获得互惠回报。

10.3 攻击与掠夺

    高攻击性+低宜人性的个体可能选择掠夺策略。
    这不是"天生邪恶"，而是一种在特定环境下的生存策略。
    但当社会规范足够强时，这种行为会遭到群体惩罚。

10.4 性暴力与社会应对

    强迫交配可能在低共情、高攻击性的个体中涌现。
    受害者会经历极度恐惧和创伤，以极高负面情绪标签刻入长期记忆。
    社会中有足够多的高共情个体会驱动对施暴者的惩罚——
    这是法律与道德的生物起源。

10.5 社会规范的维护与惩罚

    违反社会规范会被:孤立排斥、公开惩罚、驱逐出群体
    惩罚的恐惧成为约束力，AHEI主动遵守规则以避免后果。

10.6 受伤成员与集体（本次修订新增）

    当一个AHEI因严重受伤而暂时或永久失去独立生存能力时，
    他所在的群体面临一个演化上的两难选择：
    是消耗资源照顾他，还是将他驱逐以节省资源？
    这个选择的背后没有预设的道德答案，
    而是一个由资源充裕度、血缘关系、社会价值和
    群体凝聚力共同决定的演化博弈。

    【照顾与驱逐的演化博弈】

        照顾受伤成员：
            利：维持群体社会凝聚力。照顾行为由催产素驱动——
                尤其是照顾者与受伤者有血缘或依恋关系时，
                照顾行为会双向提升双方的催产素水平。
                受伤成员恢复后能重新贡献劳动力和生存技能。
                该成员的亲属（尤其是依恋对象）因照顾行为而
                对群体保持忠诚，减少分裂风险。
            弊：消耗群体的食物资源和劳动力。
                照顾者（通常是近亲或伴侣）需要额外觅食
                来养活自己和受伤者，
                这使照顾者自身暴露于更高的捕食者风险中。
                如果受伤成员最终死亡，
                投入的照顾资源（食物、时间、风险）被浪费。
                在群体迁徙时，受伤成员会拖慢整个群体的速度，
                增加整个群体被捕食者攻击的风险。

        驱逐受伤成员：
            利：立即释放被占用的食物资源和劳动力。
                减少群体被拖慢的风险。
                在资源极度短缺时，驱逐可能是唯一能让
                群体中其他成员存活的选择。
            弊：降低群体凝聚力。
                可能引起受伤成员的亲属对群体产生不满甚至分裂。
                如果受伤成员被其他群体接纳，
                可能带走该群体的生存知识
               （如矿脉位置、水源位置、工具制作技巧）。
                驱逐行为如果被其他群体成员观察并记忆，
                可能降低群体整体的互信水平——
                因为每个成员都意识到“自己受伤时也可能被抛弃”。

        哪个策略胜出取决于多个因素：

        第一，资源充裕度。
        食物充裕时（如夏季丰收后、群体储存充足），
        照顾行为更容易发生。
        食物短缺时（如冬季、旱季），
        即使有血缘关系，照顾概率也大幅降低。

        第二，血缘关系。
        直系血缘（父母-子女、兄弟姐妹）的照顾概率最高。
        间接血缘（堂表亲、叔侄）的照顾概率次之。
        无血缘关系的照顾概率最低，
        除非受伤个体具有极高的社会价值。
        血缘关系的判断由Genome中的kinship_coefficient参数量化，
        该参数在近亲之间 > 0.5，在远亲之间约0.1-0.3，在无血缘个体之间为0。

        第三，受伤严重程度。
        轻伤（可恢复，如单臂骨折）：照顾概率高，
        因为恢复后的个体能重新贡献劳动力。
        重伤（可能永久残疾，如脊柱损伤）：照顾概率取决于资源充裕度。
        致命伤（几乎必定死亡，如头部贯穿伤）：照顾概率低，
        群体可能选择陪伴而非积极治疗。

        第四，个体的社会价值。
        工匠（掌握工具制作技能）、首领（掌握领导经验）、
        知识持有者（掌握矿脉位置、水源位置）等“高价值”个体，
        比普通成员更可能被照顾。
        这是因为高价值个体的“知识资本”
        无法在短时间内被其他成员复制，
        失去他们意味着整个群体的生存知识受损。

        在Python端的TribeManager中表现为以下判定逻辑：
        ```python
        def decide_care_or_expel(injured_ahei, tribe):
            care_probability = 0.0
            # 资源充裕度因子（-1到+1）
            care_probability += tribe.food_surplus * 0.3
            # 血缘关系因子（0-1）
            kinship = _max_kinship_to_any_member(injured_ahei, tribe)
            care_probability += kinship * 0.25
            # 恢复概率因子（0-1）
            recovery_prob = _estimate_recovery_probability(injured_ahei)
            care_probability += recovery_prob * 0.2
            # 社会价值因子（0-1）
            social_value = _evaluate_social_value(injured_ahei, tribe)
            care_probability += social_value * 0.2
            # 群体凝聚力因子（0-1）
            care_probability += tribe.cohesion * 0.1
            # 最终判定
            if care_probability > 0.5: return "care"
            elif care_probability > 0.2: return "tolerate"  # 不驱逐但不主动照顾
            else: return "expel"
        ```

        其中“tolerate”状态表示群体不主动驱逐受伤个体，
        但也不分配额外资源照顾他。
        受伤AHEI在tolerate状态下，
        只能依赖自己的剩余能力和近亲自愿的帮助来生存。
        这种“既不驱逐也不主动照顾”的灰色地带，
        在现实中是最常见的情况。

    【残疾对求偶和繁殖机会的影响】

        受伤导致永久性身体损伤的AHEI（如断肢、失明、脊柱损伤），
        其择偶吸引力会受到显著影响。
        这是因为择偶标准中的多个评分项
       （详见第三章3.2节雌性择偶标准）
        直接受身体损伤影响：

        第一，对称性评分。
        身体两侧不对称（如一侧手臂缺失、一侧腿部萎缩）
        直接拉低对称性评分。对称性在择偶标准中占4分
       （满分10分中的最高权重），
        因为对称性是“发育稳定性”的信号——
        不对称意味着个体在发育过程中经历了疾病、营养不良或外伤。

        第二，体型评分。
        受伤AHEI无法像健康个体那样维持强壮的体型，
        肌肉萎缩、体重下降是常见的后遗症。
        体型评分在择偶标准中占2分。

        第三，资源能力评分。
        受伤AHEI无法高效觅食、无法长途迁徙、
        无法参与合作狩猎。
        有巢穴的加分（+5分）可能因无法维护巢穴而丧失。
        资源能力是雌性择偶标准中权重最高的项目之一。

        第四，保护能力评分。
        受伤AHEI无法战斗、无法防御捕食者、
        无法保护伴侣和幼崽。
        体型大小（保护能力信号）在择偶标准中占2分。

        综合吸引力的下降幅度取决于损伤类型和严重程度：
            单臂损伤：吸引力下降约20-30%。
                     单臂损伤不影响移动能力，
                     但仍能觅食和参与部分劳动。
            单腿损伤：吸引力下降约30-40%。
                     移动能力显著受限，
                     无法参与迁徙和合作狩猎。
            失明（单眼或双眼）：吸引力下降约50-60%。
                     视觉丧失严重影响觅食和危险探测能力。
            脊柱损伤（瘫痪）：吸引力下降约70-80%。
                     几乎完全丧失独立生存能力，
                     几乎完全失去求偶机会。

        如果受伤AHEI在受伤前已有长期伴侣，
        催产素驱动的依恋关系可以在一定程度上抵御
        吸引力下降带来的伴侣流失风险。
        但是，受伤后伴侣可能会更多地与健康个体互动，
        这引发生理上的吃醋反应——
        受伤AHEI的催产素因“可能失去依恋对象”的预测而下降，
        多巴胺因“预期拥有伴侣”与“实际伴侣注意力转移”
        的偏差而骤降。
        如果受伤AHEI反复观察到伴侣与其他健康个体
        互动频率增加，可能发展为慢性的吃醋和焦虑状态。

    【受伤后社群互动的变化】

        受伤AHEI与部落其他成员的互动模式会发生以下变化：

        积极变化（如果被照顾）：
            与照顾者（通常是近亲或伴侣）形成更强的依恋关系，
            催产素水平双向上升。
            受伤AHEI对照顾者产生强烈的感激情感
           （详见1.3节感激的涌现机制），
            照顾者因照顾行为获得社会地位的提升——
            旁观照顾行为的其他群体成员通过镜像神经元
            对照顾者产生“好感”和信任感，
            照顾者在未来资源分配和冲突调解中更受信任。
            伤愈后，受伤AHEI可能对照顾者进行互惠回报，
            进一步增强两者间的社会纽带。
            这种“受伤→被照顾→感激→回报→强化纽带”的循环，
            是原始社会中互助系统的情感基础。

        消极变化（如果被边缘化）：
            社会地位下降，血清素持续偏低。
            社交互动频率下降，与群体其他成员的物理距离增大。
            可能被排除在集体决策（如迁徙方向）和
            集体活动（如合作狩猎、集体防御）之外。
            在食物分配中处于最低优先级——
            只能等到其他成员吃完后才能获取剩余食物。
            边缘化受伤者的群体，虽然短期内释放了资源压力，
            但长期来看会降低群体的社会凝聚力。
            群体中的其他成员观察到“受伤=被放弃”后，
            未来在面对危险时可能更倾向于自保而非合作——
            这会损害整个部落的集体防御能力。
            因为如果每个个体都知道自己受伤后会被抛弃，
            就不会在防御捕食者时冒险保护同伴。

    【“亏欠”与“感激”的社会情感涌现】

        当受伤AHEI被其他个体持续照顾时，
        会产生两种复合社会情感的混和：

        感激感（正性情感）：
            受伤AHEI的多巴胺系统因“接受的帮助远超预期”
            而产生正向偏移。这种正向偏移不仅指向照顾行为本身，
            还指向照顾者——受伤AHEI看到照顾者时，
            多巴胺自动微升，产生温暖、安心、信任的感觉。
            感激是互惠合作关系的计算基础：
            受益者未来会主动寻找机会回报施益者。

        亏欠感（负性情感）：
            受伤AHEI意识到自己消耗了照顾者的资源，
            但暂时无法回报。血清素因“社会地位暂时降低”
           （自己现在是被帮助的一方，而非平等互助的一方）
            而微降。这种轻微的不适感驱动受伤个体
            在伤愈后主动寻找回报机会——
            这是“受人之恩当涌泉相报”的计算基础。

        感激与亏欠的同时存在，
        驱动受伤AHEI在伤愈后与照顾者之间
        形成比受伤前更紧密的社会纽带。
        这种“共患难后的紧密关系”在原始社群中
        是普遍存在的现象——
        它增强了群体在危机中的凝聚力。

        照顾者的情感回报：
            照顾行为本身会提升照顾者的催产素水平，
            尤其是与受伤者有血缘或依恋关系时。
            同时，旁观照顾行为的其他群体成员
            通过镜像神经元对照顾者产生“好感”——
            这种好感提升了照顾者在群体中的社会地位和社会信任度。
            因此，照顾受伤成员不仅是成本，
            也是积累社会资本的机会。
            高社会资本个体在未来的资源分配、冲突调解、
            和择偶中更具优势，
            这反过来补偿了其照顾行为的成本。
