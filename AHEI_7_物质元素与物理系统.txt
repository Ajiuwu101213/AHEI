第一章  统一物理属性系统

1.1 万物共有的物理属性

    在AHEI的世界中，每一个实体——无论是一块燧石、一段木头、一滴水、
    还是一个AHEI的身体部位——都拥有以下标准化的物理属性。
    
    这意味着任何两个物体之间的交互结果，都可以由一套通用的物理规则
    自动判定，不需要为每种物质组合单独写代码。

1.2 物理属性详细定义

| 属性 | 英文名 | 单位 | 说明 |
|------|--------|------|------|
| 质量 | mass | 千克(kg) | 物体所含物质的量。影响惯性、冲击力、搬运体力消耗 |
| 体积 | volume | 立方米(m³) | 物体占据的空间。影响浮力、能否通过狭小空间 |
| 密度 | density | kg/m³ | 质量/体积。影响浮力（密度<水密度则漂浮） |
| 坚硬度 | hardness | 莫氏(1-10) | 抵抗刮擦和穿刺的能力。碰撞中硬度高的一方占优势 |
| 弹性 | elasticity | 0-1 | 0=完全非弹性（碰撞后不反弹），1=完全弹性 |
| 摩擦系数 | friction | 0-1 | 表面粗糙度。影响斜面上能否站稳、抓握是否牢固 |
| 破坏阈值 | break_threshold | 牛顿(N) | 承受力的极限。超过此值则碎裂、折断或变形 |
| 抗拉强度 | tensile_strength | MPa | 承受拉力的极限 |
| 抗压强度 | compressive_strength | MPa | 承受压力的极限 |
| 重心位置 | center_of_mass | 相对坐标 | 质量分布的中心。影响平衡感和倾倒方向 |
| 熔点 | melting_point | °C | 物质从固态变为液态的温度 |
| 沸点 | boiling_point | °C | 物质从液态变为气态的温度 |
| 热导率 | thermal_conductivity | W/(m·K) | 热传导速度。影响触觉感知到的"冷热" |
| 毒性 | toxicity | 0-1 | 0=完全无毒，1=剧毒 |
| 可燃性 | flammability | 0-1 | 0=完全不可燃，1=极易燃 |
| 导电性 | conductivity | S/m | 电导率。影响能否用作电线或绝缘体 |

1.3 物理属性在代码中的存储（Godot Resource系统）

    所有物质的物理属性存储在自定义MaterialData Resource中：
    
    ```gdscript
    # MaterialData.gd (自定义Resource)
    class_name MaterialData
    extends Resource
    
    @export var material_id: String = ""
    @export var display_name: String = ""
    @export var density: float = 1000.0          # kg/m³
    @export var hardness: float = 1.0             # 莫氏(1-10)
    @export var elasticity: float = 0.5           # 0-1
    @export var friction: float = 0.5             # 0-1
    @export var break_threshold: float = 1000.0   # 牛顿
    @export var melting_point: float = 1000.0     # °C
    @export var thermal_conductivity: float = 1.0 # W/(m·K)
    @export var toxicity: float = 0.0             # 0-1
    @export var flammability: float = 0.0         # 0-1
    @export var conductivity: float = 0.0         # S/m
    ```

    所有物质的MaterialData资源集中存储在 `resources/materials/` 目录下，
    以 `.tres` 文件形式。游戏启动时由MaterialRegistry加载到字典中：
    
    ```gdscript
    # MaterialRegistry.gd (Autoload)
    extends Node
    
    var materials: Dictionary = {}  # {material_id: MaterialData}
    
    func _ready() -> void:
        _load_all_materials()
    
    func _load_all_materials() -> void:
        var dir = DirAccess.open("res://resources/materials/")
        if dir:
            dir.list_dir_begin()
            var file_name = dir.get_next()
            while file_name != "":
                if file_name.ends_with(".tres"):
                    var mat = load("res://resources/materials/" + file_name) as MaterialData
                    if mat:
                        materials[mat.material_id] = mat
                file_name = dir.get_next()
    
    func get_material(id: String) -> MaterialData:
        return materials.get(id, null)
    ```

第三章  硬度对抗与破坏判定
================================================================================

3.1 硬度对抗规则

    当两个物体发生碰撞或摩擦时，硬度更高的一方主导破坏过程。
    
    判定公式：
        if A.hardness > B.hardness:
            A主导破坏，B的受损程度 = 碰撞力 × A.hardness / B.hardness
        elif B.hardness > A.hardness:
            B主导破坏，A的受损程度 = 碰撞力 × B.hardness / A.hardness
        else:
            双方同等程度磨损
    
    受损程度超过物体的break_threshold时，物体碎裂、折断或变形。

3.2 破坏阈值与碎裂

    每个物体有break_threshold值（单位：牛顿），表示能承受的最大冲击力。
    
    当实际冲击力超过break_threshold时：
        - 石块：碎裂为2-4个不规则小块
        - 木材：沿纤维方向劈裂
        - 金属：塑性变形或断裂
        - 骨骼：骨折，该部位丧失功能
        - 工具：耐久度下降，降到0时损坏
    
    碎裂后的碎片继承原物体的物理属性，但质量和体积减小。

3.3 硬度对抗表（示例）

    以下表格展示了常见物质之间的硬度对抗结果：

| A \ B | 木材(4) | 石(7) | 铜(3) | 铁(5) | 钢(7) | 血肉(0.5) |
|-------|---------|-------|-------|-------|-------|-----------|
| 木材  | 双方磨损 | 木被破坏 | 木被破坏 | 木被破坏 | 木被破坏 | 木无伤 |
| 石    | 石碎木 | 双方碎裂 | 石被破坏 | 石可能裂 | 石被破坏 | 石无伤 |
| 铜    | 铜无伤 | 铜被破坏 | 双方磨损 | 铜被破坏 | 铜被破坏 | 铜无伤 |
| 铁    | 铁无伤 | 铁可能裂 | 铁无伤 | 双方磨损 | 铁被破坏 | 铁无伤 |
| 钢    | 钢无伤 | 钢可能裂 | 钢无伤 | 钢无伤 | 双方磨损 | 钢无伤 |

    这个规则确保了：你用铜镐能挖铜矿（硬度相近），但挖铁矿效率极低；
    用铁镐挖铁矿效率正常；用石斧能砍树但不能砍石头。

3.4 Godot实现（碰撞信号与材质查询）

    在Godot中，所有可破坏物体都继承自一个共同的DestroyableObject类：
    
    ```gdscript
    # DestroyableObject.gd
    class_name DestroyableObject
    extends RigidBody3D
    
    @export var material_id: String = ""
    var material_data: MaterialData = null
    var current_integrity: float = 1.0
    
    func _ready() -> void:
        material_data = MaterialRegistry.get_material(material_id)
        current_integrity = material_data.break_threshold if material_data else 1000.0
        self.body_entered.connect(_on_body_entered)
    
    func _on_body_entered(body: Node) -> void:
        if body is DestroyableObject:
            _resolve_collision(body)
    
    func _resolve_collision(other: DestroyableObject) -> void:
        var impact_force = _calculate_impact_force(other)
        var my_hardness = material_data.hardness if material_data else 1.0
        var other_hardness = other.material_data.hardness if other.material_data else 1.0
        
        if my_hardness > other_hardness:
            # 我方硬度更高，对方受损
            var damage = impact_force * my_hardness / other_hardness
            other.apply_damage(damage)
        elif other_hardness > my_hardness:
            # 对方硬度更高，我方受损
            var damage = impact_force * other_hardness / my_hardness
            self.apply_damage(damage)
        else:
            # 同等磨损
            self.apply_damage(impact_force * 0.5)
            other.apply_damage(impact_force * 0.5)
    
    func apply_damage(force: float) -> void:
        current_integrity -= force
        if current_integrity <= 0:
            _on_destroyed()
    
    func _on_destroyed() -> void:
        # 生成碎片、播放音效、粒子效果
        queue_free()
    ```


================================================================================
第四章  压强与伤害类型
================================================================================

4.1 压强计算公式

    压强 = 力 / 接触面积
    
    同样的力，作用在极小的面积上会产生巨大的压强。
    这就是为什么刀刃能切割、针能刺穿——不是因为力量大，而是因为压强高。

4.2 刀刃压强（割伤）原理

    一把燧石刀的刃口接触面积约为0.0001 m²（假设刃口宽0.1mm，接触段长1cm）。
    施加50N的力（约5kg重量）→ 压强 = 50 / 0.0001 = 500,000 Pa。
    这个压强足以破坏大多数生物组织的细胞结构，造成割伤。
    
    判定：如果压强超过目标材料的抗压强度→割伤成功。
    割伤的效果：软组织被分离→流血→health扣减。

4.3 钝器压强（淤伤）原理

    同样的50N力，如果通过钝器（接触面积0.01 m²）施加→压强 = 5,000 Pa。
    这个压强不足以破坏皮肤表面，但足以损伤皮下毛细血管→淤伤。
    
    判定：压强超过皮下组织抗压强度但低于皮肤抗压强度→淤伤。
    淤伤效果：health轻微扣减，受击部位暂时变色。

4.4 压强对AHEI的影响

    - 刃具割伤→流血持续扣health，直到包扎或血液凝固
    - 钝器砸伤→即时扣health，可能骨折
    - 摔倒：体重+落地速度决定冲击力，与地面硬度共同决定伤害
    - 压伤：被重物压住→压强超过组织承受力→持续伤害

4.5 冲击伤的物理判定

    冲击伤是钝器碰撞、拳头击打、被石头砸中这类伤害的总称。
    致伤原理是碰撞力通过较大的接触面积传递，压强不足以穿透皮肤但能损伤皮下组织和骨骼。

    判定流程：
        1. 碰撞事件触发 → 获取碰撞力（牛顿）和接触面积（m²）
        2. 计算压强 = 碰撞力 / 接触面积
        3. 如果压强 < 皮肤抗压强度（约2 MPa）→ 仅淤伤，health扣减1-3
        4. 如果压强 > 皮肤抗压强度 → 软组织挫伤，health扣减5-15
        5. 如果碰撞力 > 骨骼断裂阈值（默认30N × 部位乘数）→ 骨折

    不同部位的骨骼断裂阈值：

    | 部位 | force_multiplier | 断裂阈值(N) | 骨折后果 |
    |------|-----------------|------------|---------|
    | 头骨 | 2.5 | 75 | 认知能力下降，视觉模糊，可能昏迷 |
    | 肋骨 | 1.5 | 45 | 呼吸时持续微痛，体力恢复速度降低30% |
    | 上臂骨 | 1.0 | 30 | 该臂丧失抓取和攻击能力 |
    | 前臂骨 | 0.8 | 24 | 该臂部分功能丧失 |
    | 大腿骨 | 1.5 | 45 | 移动速度减半，需单腿跳跃 |
    | 小腿骨 | 1.2 | 36 | 移动速度降低40% |
    | 手指骨 | 0.3 | 9 | 该手指无法使用 |

4.6 重力伤（坠落）的物理判定

    坠落伤害由体重和落地速度共同决定的动能转化为冲击力。

    判定流程：
        1. 检测AHEI从高处落地的速度（通过CharacterBody3D的velocity.y）
        2. 计算落地冲击力 = 体重 × 落地速度 / 减速时间（默认0.05秒）
        3. 计算压强 = 冲击力 / 接触面积（脚底约0.04 m²）
        4. 如果压强 > 腿部骨骼断裂阈值 → 腿骨折
        5. 如果压强 > 脊柱断裂阈值 → 脊柱骨折（下半身瘫痪）
        6. 如果头部着地（概率判定）→ 头骨骨折，高概率死亡

    坠落高度与伤害对照（以70kg体重计）：

    | 坠落高度 | 落地速度 | 冲击力 | 可能后果 |
    |---------|---------|--------|---------|
    | <2米 | <6.3 m/s | <8,800 N | 轻微淤伤或无伤 |
    | 2-5米 | 6.3-10 m/s | 8,800-14,000 N | 腿骨可能骨折，软组织挫伤 |
    | 5-10米 | 10-14 m/s | 14,000-19,600 N | 腿部严重骨折，可能脊柱损伤 |
    | 10-20米 | 14-20 m/s | 19,600-28,000 N | 多处骨折，高概率死亡 |
    | >20米 | >20 m/s | >28,000 N | 几乎必定死亡 |

4.7 压力伤（挤压）的物理判定

    挤压伤是因被重物持续压住所致的伤害，压强超过组织承受力会导致细胞坏死和血液循环中断。

    判定流程：
        1. 检测AHEI被重物压住（RigidBody3D持续接触）
        2. 计算压力 = 重物质量 × 9.8
        3. 计算压强 = 压力 / 接触面积
        4. 如果压强 > 5 MPa → 局部组织开始坏死
        5. 持续时间越长，伤害越重

    挤压时间与伤害：

    | 持续时间 | 伤害 |
    |---------|------|
    | <10秒 | 轻微淤伤 |
    | 10-30秒 | 软组织挫伤，health中度扣减 |
    | 30-60秒 | 肌肉坏死开始，health持续扣减 |
    | 1-5分钟 | 骨骼可能断裂，被压部位功能永久受损 |
    | >5分钟 | 被压部位可能需截肢，高概率死亡 |

4.8 贯穿伤的物理判定

    贯穿伤由尖锐物体（矛尖、箭尖、兽牙）刺入身体所致。
    致伤原理是极小接触面积（约0.0001 m²）产生极高压强，穿透皮肤和深层组织。

    判定流程：
        1. 尖锐物体与AHEI身体碰撞
        2. 计算压强 = 碰撞力 / 接触面积（刀尖/箭尖/牙尖约0.0001 m²）
        3. 如果压强 > 皮肤抗压强度（约2 MPa）→ 皮肤被穿透
        4. 如果穿透深度 > 肌肉厚度 → 可能伤及内脏或血管

    贯穿部位与后果：

    | 贯穿部位 | 后果 |
    |---------|------|
    | 四肢 | 局部功能下降，流血 |
    | 腹部 | 内脏可能受损，高概率感染 |
    | 胸腔 | 肺部可能被刺穿，呼吸困难 |
    | 颈部 | 大血管破裂，急速失血，高概率死亡 |
    | 头部 | 颅骨可能被穿透，极高概率死亡 |

4.9 割裂伤的物理判定

    割裂伤是刀刃沿平行于皮肤方向运动，压强超过组织抗压强度将软组织分离。

    判定流程：
        1. 刀刃与AHEI身体碰撞，且刀刃方向与皮肤有相对滑动
        2. 计算压强 = 碰撞力 / 刃口接触面积（约0.00005 m²）
        3. 如果压强 > 皮肤抗压强度 → 皮肤被切开
        4. 切割深度由力和刃口锋利度决定

    割裂伤的特殊后果——流血：
        - 浅层割伤：每秒扣0.5 health，持续30-60秒后自动凝固
        - 深层割伤：每秒扣2-5 health，需包扎止血，否则持续扣减至死亡
        - 感染风险：伤口接触泥土、腐肉、粪便后，感染概率大幅上升

4.10 温度伤的物理判定

    温度伤由极端温度破坏细胞结构和功能所致。

    烧伤等级（接触火焰或高温物体）：

    | 等级 | 温度范围 | 表现 | health扣减 |
    |------|---------|------|-----------|
    | 一级 | 45-55°C | 局部变红，疼痛 | -5 |
    | 二级 | 55-70°C | 起水泡，剧痛 | -15 |
    | 三级 | >70°C | 组织坏死，焦黑 | -30（永久疤痕） |

    冻伤等级（接触极低温或长时间处于严寒）：

    | 等级 | 温度范围 | 表现 | health扣减 |
    |------|---------|------|-----------|
    | 一级 | 0°C ~ -10°C | 局部麻木，皮肤发红 | -3 |
    | 二级 | -10°C ~ -25°C | 起水泡，皮肤发紫 | -10 |
    | 三级 | <-25°C | 组织冻结坏死，变黑 | -25（永久损伤） |

4.11 化学灼伤的物理判定

    化学灼伤由腐蚀性物质（强酸、强碱）接触皮肤，破坏细胞膜和蛋白质结构。

    判定流程：
        1. AHEI皮肤接触腐蚀性物质
        2. 读取物质的corrosiveness参数（0-1）
        3. health扣减 = corrosiveness × 接触面积 × 接触时间

    化学灼伤等级：

    | 等级 | corrosiveness | 表现 | 恢复 |
    |------|-------------|------|------|
    | 轻度 | 0.1-0.3 | 皮肤变红，刺痛 | 1-3天 |
    | 中度 | 0.3-0.6 | 起水泡，剧痛 | 5-15天，可能留疤 |
    | 重度 | 0.6-1.0 | 组织坏死，深及骨骼 | 永久疤痕，功能永久受损 |

4.12 Godot实现（碰撞点接触面积计算）

    在Godot中，碰撞点信息可通过碰撞信号获取：
    
    ```gdscript
    func _on_body_entered(body: Node) -> void:
        # 获取碰撞点（需要从PhysicsDirectBodyState获取）
        var state = PhysicsServer3D.body_get_direct_state(self.get_rid())
        if state:
            var contact_count = state.get_contact_count()
            for i in range(contact_count):
                var contact = state.get_contact_local_position(i)
                var impact = state.get_contact_impulse(i)
                var area = _estimate_contact_area(body, contact)
                if area > 0:
                    var pressure = impact.length() / area
                    _apply_pressure_damage(pressure, contact)
    ```

    接触面积估算逻辑：
    ```gdscript
    func _estimate_contact_area(body: Node, contact_point: Vector3) -> float:
        # 如果是刀刃，接触面积很小
        if body.has_method("is_sharp") and body.is_sharp():
            return 0.0001  # 约0.1mm×1cm
        # 如果是钝器，接触面积较大
        elif body.has_method("is_blunt") and body.is_blunt():
            return 0.01  # 约10cm²
        # 默认（如拳头）
        return 0.005  # 约5cm²
    ```

第五章  碰撞与动量系统

5.1 碰撞检测

    在Godot中，碰撞检测通过RigidBody3D的body_entered信号或
    Area3D的body_entered信号实现：
    
    ```gdscript
    # 连接到RigidBody3D
    self.body_entered.connect(_on_collision)
    
    func _on_collision(body: Node) -> void:
        if body is DestroyableObject:
            var relative_velocity = self.linear_velocity - body.linear_velocity
            var impact_force = relative_velocity.length() * self.mass
            _resolve_physics_collision(body, impact_force)
    ```

5.2 碰撞响应（质量比+弹性系数）

    碰撞响应公式：
        impulse_magnitude = -(1 + elasticity) × velocity_along_normal
                          / (1/mass_a + 1/mass_b)
    
    质量更大的物体在碰撞中运动状态变化更小。
    弹性系数决定碰撞后反弹的程度（石头弹得多，泥巴几乎不弹）。

5.3 反作用力与触觉反馈

    当AHEI用手挥动工具敲击物体时：
        工具与物体碰撞→产生冲击力
        冲击力通过工具柄传到AHEI手上
        触觉系统检测到这个力→进入感官处理
        →AHEI"感觉"到了敲击的震动
    
    Godot实现：碰撞时计算反作用力，通过AHEI的触觉系统接口传递：
    ```gdscript
    func _on_tool_collision(tool: Node3D, target: Node3D, impact: Vector3) -> void:
        var feedback = {
            "force": impact.length(),
            "direction": impact.normalized(),
            "contact_point": _get_contact_point(tool, target)
        }
        touch_system.process_impact(feedback)
    ```

第六章  重力与惯性系统
================================================================================

6.1 重力加速度（Godot的ProjectSettings）

    在Godot中，重力通过ProjectSettings配置：
        路径：Project -> Project Settings -> Physics -> 3D -> Gravity
        默认值：9.8 m/s²
    
    所有RigidBody3D自动受重力影响。自定义重力可通过修改gravity_scale属性。

6.2 牛顿第二定律（F=ma）

    物体的加速度与其所受合力成正比，与其质量成反比。
    质量越大的物体越难被推动，越难被停止。
    
    在Godot中，通过RigidBody3D的mass属性控制质量：
    ```gdscript
    rigid_body.mass = material_data.density * calculated_volume
    ```

6.3 水中浮力

    浮力 = 物体排开水的体积 × 水的密度(1000 kg/m³) × g
    如果物体密度 < 1000 → 浮力 > 重力 → 浮起
    如果物体密度 > 1000 → 浮力 < 重力 → 沉没
    
    Godot实现：在水体Area3D的body_entered信号中施加向上力：
    ```gdscript
    func _on_water_body_entered(body: Node3D) -> void:
        if body is RigidBody3D:
            var displaced_volume = _calculate_displaced_volume(body)
            var buoyancy = displaced_volume * 1000.0 * 9.8
            body.apply_central_force(Vector3.UP * buoyancy)
    ```

6.4 空气阻力

    空气阻力 = 速度² × 截面积 × 空气密度 × 阻力系数 × 0.5
    在正常速度下影响极小，但在高速（如坠落）时显著。
    
    Godot中通过RigidBody3D的linear_damp和angular_damp属性模拟空气阻力。

第七章  粘性与湿度系统
================================================================================

7.1 万物皆有湿度

    湿度(moisture)是万物的动态属性，范围0%（绝对干燥）到100%（完全饱和）。
    
    湿度变化规则：
        - 暴露在雨中→湿度上升
        - 浸泡在水中→湿度迅速升到100%
        - 放置于干燥环境→湿度缓慢下降
        - 靠近火源→湿度迅速下降

7.2 万物皆有粘性

    粘性由两部分组成：
        - 固有粘性(intrinsic_stickiness)：物体天然的粘附力，如树脂天生粘性极高
        - 湿度修正：水分增加有效粘性（如湿沙比干沙更粘）

7.3 有效粘性计算公式

    有效粘性 = 固有粘性 × (1 + moisture × moisture_factor)
    
    对于大多数物质，moisture_factor在0.3-1.0之间。
    这意味着湿度越高的物质，其粘性越强。

7.4 油脂类粘性系数表

| 油脂类型 | 固有粘性(0-1) | 密度(kg/m³) | 熔点范围(°C) | 特性 |
|---------|-------------|-------------|-------------|------|
| 动物脂肪(生) | 0.75 | 900 | 30-50 | 易涂抹，可作润滑 |
| 动物脂肪(熬制) | 0.85 | 880 | 35-55 | 更纯净，粘性更强 |
| 植物油 | 0.55 | 920 | 常温液态 | 流动性好，粘性较低 |
| 蜂蜡 | 0.90 | 960 | 62-65 | 极高粘性，可作胶水 |
| 松脂/树脂 | 0.95 | 1050 | 60-80软化 | 最强天然粘合剂 |
| 焦油/沥青 | 0.98 | 1100 | 50-100软化 | 极粘稠，后期建材 |

7.5 粘性与湿度的感官反馈

    AHEI通过触觉系统感知物体的粘性和湿度：
        - 皮肤接触潮湿物体→"湿漉漉"的触觉信号
        - 分离两个粘性物体时需要额外力→"粘手"的感知
        - 湿冷物体触感：水的导热性能好，接触皮肤时迅速带走热量
          →温度触觉传感器发出"冰冷"信号
          →这就是"刺骨的湿冷"，比单纯的寒冷更难忍受

7.6 Godot实现（材质参数+Area3D检测）

    粘性和湿度作为可变的材质参数存储在物体上：
    ```gdscript
    # 粘性湿度组件
    class_name StickyComponent
    extends Node
    
    @export var intrinsic_stickiness: float = 0.0
    @export var moisture: float = 0.0
    @export var moisture_factor: float = 0.5
    
    var effective_stickiness: float:
        get:
            return intrinsic_stickiness * (1.0 + moisture * moisture_factor)
    
    func apply_moisture(amount: float) -> void:
        moisture = clampf(moisture + amount, 0.0, 1.0)
    
    func apply_heat(intensity: float, delta: float) -> void:
        moisture = maxf(0.0, moisture - intensity * delta * 0.1)
    ```

第八章  物理背包系统
================================================================================

8.1 物理容器的类型

    背包是物理存在的容器，不是抽象的物品栏界面。

| 容器类型 | 制作材料 | 容积(L) | 自重(kg) | 可携带物品类型 | 获取方式 |
|---------|---------|---------|---------|--------------|---------|
| 藤草编织筐 | 藤蔓、草绳 | 20 | 0.5 | 固体块状物（矿石、木材） | 后天学习编织 |
| 兽皮袋 | 兽皮、筋线 | 15 | 0.3 | 小型物品、粉末、浆果 | 后天学习缝制 |
| 木箱 | 木板、藤蔓 | 50 | 3 | 所有固体物品 | 后天学习制作 |
| 陶罐 | 黏土烧制 | 10 | 2 | 液体、粉末、小颗粒 | 后天学习制陶 |
| 徒手抱持 | 无 | 1-10 | 0 | 大块单一物品 | 本能（无需学习） |

8.2 物品的放入与取出

    放入物品：AHEI用手抓住物品→移动到容器口附近→松开手→物品物理落入容器。
    如果容器已满，物品会掉出或无法放入。
    
    取出物品：AHEI将手伸入容器（碰撞检测区域内）→
    选择触碰到的物品抓取。如果物品被压在最底层，需要先移开上面的物品。

8.3 重量限制与体积限制

    重量限制：AHEI的最大携带重量由力量属性和体力状态决定。
    超过负重上限→移动速度下降、体力消耗加快，极端超重将无法移动。
    
    体积限制：容器有固定的物理容积。大件物品可能一个就占满空间，
    小颗粒物品（如浆果、沙粒）可大量堆叠。

8.4 与传统游戏背包的区别

| 特性 | 传统游戏背包 | AHEI物理背包 |
|------|------------|-------------|
| 物品存储 | 抽象数据网格，每格放一种物品 | 物理实体有三维几何空间 |
| 取出物品 | 点击图标即可 | 需要用手伸进容器抓取特定物品 |
| 重量系统 | 累加数值，超重可能无法奔跑 | 实时物理模拟，影响移动、体力、平衡 |
| 整理方式 | 自动排序 | 需要手动摆放，大件物品压在下面更难取出 |
| 丢失风险 | 通常不会丢失背包 | 容器可被破坏、掉落、被他人拿走 |

8.5 Godot实现（容器节点+可拾取物）

    在Godot中，容器是一个包含Area3D的Node3D：
    ```gdscript
    # Container.gd
    class_name Container
    extends Node3D
    
    @export var max_volume: float = 20.0  # 升
    @export var self_mass: float = 0.5    # kg
    @export var can_hold_liquid: bool = false
    
    var current_volume: float = 0.0
    var items: Array[RigidBody3D] = []
    
    func can_accept_item(item: RigidBody3D) -> bool:
        var item_volume = _calculate_volume(item)
        return current_volume + item_volume <= max_volume
    
    func add_item(item: RigidBody3D) -> void:
        item.freeze = true  # 放入后锁定物理
        item.reparent(self)
        items.append(item)
        current_volume += _calculate_volume(item)
    
    func remove_item(item: RigidBody3D) -> void:
        item.freeze = false
        item.reparent(get_tree().current_scene)
        items.erase(item)
        current_volume -= _calculate_volume(item)
    ```

9.1 可食用物质的消化结果

9.2 不可食用物质的后果

| 物质 | 吞食后果 | 致命性 |
|------|---------|--------|
| 石头/大块矿石 | 牙齿崩裂、消化道堵塞 | 大量可致命 |
| 沙子/泥土 | 少量无影响，大量堵塞 | 大量可致命 |
| 黏土 | 吸水膨胀→更严重堵塞 | 大量可致命 |
| 木屑 | 消化道划伤 | 一般不致命 |

9.3 有毒物质的毒性机制

    重金属（铅、汞、砷等）：
        铅：累积性神经损伤，认知能力下降，贫血，不孕不育
        汞：神经系统被噪声覆盖→行为失常，不可逆
        砷：急性→剧烈腹痛、呕吐、数小时死亡
            慢性→皮肤色素沉着、角化、多器官衰竭
    
    生物毒素（毒蘑菇、腐败食物产生的细菌毒素）：
        毒素进入血液→肝脏代谢
        代谢速度决定存活概率
        免疫系统足够强时可能存活，并产生抗体记忆

9.4 化学灼伤与腐蚀

    强酸/强碱接触皮肤→局部化学灼伤：
        - 局部health扣减
        - 接触部位皮肤颜色改变
        - 重度灼伤→留下永久疤痕
        - 眼睛接触→暂时或永久失明

9.5 温度伤的触觉与生理反馈

    当AHEI接触高温物体（>45°C）时：
        - 皮肤温度传感器产生强烈的"灼热"触觉信号
        - 自主神经强制激活交感模式（疼痛→应激反应）
        - 本能行为驱动：立即缩回接触部位，后退远离热源
        - 持续接触导致烧伤（详见4.10节温度伤等级判定）

    当AHEI接触极低温物体（<0°C）或处于严寒环境时：
        - 皮肤温度传感器产生"针扎般"的冰冷触觉信号
        - 身体自动颤抖（模拟：MotorJoint添加随机微小抖动）
        - 本能行为驱动：寻找温暖源，蜷缩身体减少散热
        - 持续暴露导致冻伤（详见4.10节冻伤等级判定）

9.6 疼痛的生理-认知闭环

    任何伤害类型都会触发AHEI的疼痛反馈回路：
        1. 物理伤害事件发生→触觉传感器产生高强度的"损伤"信号
        2. 信号传入大脑→预测编码网络产生巨大的预测误差（预期"身体完好"→实际"身体受损"）
        3. 多巴胺骤降→产生"不愉快"的心理状态
        4. 自主神经切到交感模式→应激反应（心跳加速、痛觉暂时抑制）
        5. 长期记忆中标记该场景/物体/动作为"危险"
        6. 未来遇到类似场景时，预测误差提前升高→恐惧→回避行为

    这一闭环是AHEI学习"什么会伤害我"的核心机制，也是所有恐惧和回避行为的生理基础。

10.1 物理材质资源（PhysicsMaterial）

    在Godot中为不同表面创建PhysicsMaterial资源，控制摩擦和弹性：
    ```gdscript
    # 创建示例
    var wood_physics = PhysicsMaterial.new()
    wood_physics.friction = 0.7
    wood_physics.bounce = 0.2
    
    var ice_physics = PhysicsMaterial.new()
    ice_physics.friction = 0.05
    ice_physics.bounce = 0.1
    ```
    将PhysicsMaterial分配给碰撞体：`collision_shape.set_physics_material_override(wood_physics)`

10.2 RayCast3D交互检测

    用于玩家交互、AHEI视觉、工具使用等：
    ```gdscript
    # PlayerInteraction.gd
    @onready var ray = $RayCast3D
    
    func _physics_process(delta: float) -> void:
        ray.force_raycast_update()
        if ray.is_colliding():
            var target = ray.get_collider()
            if Input.is_action_just_pressed("interact"):  # E键
                if target.has_method("on_interact"):
                    target.on_interact(self)
    ```

10.3 物品物理拾取（RigidBody3D+Joint3D）

    使用Generic6DOFJoint3D或PinJoint3D实现物理抓取：
    ```gdscript
    func pickup_item(item: RigidBody3D) -> void:
        var joint = Generic6DOFJoint3D.new()
        joint.node_a = self.get_path()
        joint.node_b = item.get_path()
        add_child(joint)
        item.freeze = false
    ```

10.4 材质属性数据管理

    使用自定义Resource存储所有材质数据（见1.3节MaterialData），
    在MaterialRegistry.gd（Autoload）中加载和管理所有材质。
    任何需要查询物理属性的地方，通过MaterialRegistry.get_material(id)获取。
