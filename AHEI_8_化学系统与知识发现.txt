第六章  火系统（本次修订新增）
================================================================================

【设计总则】
火不是预设的“科技解锁项”，而是物理世界中一个独立的动态现象。
AHEI必须通过观察（闪电击中树木引发山火）、偶然发现（燧石敲击产生火花点燃干草）、
或先辈教学来学会生火和用火。火的所有行为——生成、蔓延、加热、熄灭——
都由统一的物理规则自动判定。

6.1 火的生成方式

    火的本质是可燃物与氧气在高温下的剧烈氧化反应。
    在AHEI世界中，火的生成方式有六种，每种有不同的成功概率和所需条件。
    这些方式不是预设的“合成配方”，而是AHEI通过观察或实验发现的物理规律。

| 生火方式 | 所需条件 | 成功概率 | 所需时间 | 发现难度 |
|---------|---------|---------|---------|---------|
| 自然火源引燃 | 火把/篝火+可燃物 | 100% | 1-3秒 | 极低（观察即可学会） |
| 燧石打火 | 燧石+黄铁矿（或高碳钢）+火绒 | 30-60% | 3-10秒 | 低 |
| 钻木取火 | 硬木棍+软木板+火绒 | 10-25% | 20-60秒 | 中 |
| 火镰取火 | 火镰+燧石+火绒（木炭布最佳） | 50-80% | 5-15秒 | 中 |
| 放大镜取火 | 凸透镜+阳光+火绒 | 80% | 5-20秒 | 高（需玻璃科技） |
| 火柴（后期） | 火柴+摩擦面 | 90% | 1秒 | 极高（需化学科技） |

    成功概率受以下因素影响：
        - 火绒质量：干燥火绒（moisture<10%）→成功概率×1.0
                    潮湿火绒（moisture>30%）→成功概率×0.3
                    极湿火绒（moisture>60%）→完全无法点燃
        - 风速：微风（<5m/s）→成功概率×1.0
               中风（5-15m/s）→成功概率×0.6（火花被吹散）
               强风（>15m/s）→成功概率×0.2
        - 操作者技能：每次成功生火+1点生火技能（0-100）
                     技能每提高10点，成功概率+3%

    Godot实现：
        当AHEI手持燧石和火绒进行交互时，Godot端执行以下判定：
        1. 检测手持物品是否为燧石+火绒
        2. 检测火绒湿度（从moisture参数读取）
        3. 检测当前风速（从GameState.wind读取）
        4. 计算成功概率，随机判定
        5. 成功→在火绒位置生成一个火焰粒子（GPUParticles3D）
        6. 失败→火绒不变，可重复尝试

6.2 火的蔓延规则

    火焰是一个动态实体，遵循以下物理规则在可燃物之间蔓延：

    【风向驱动】
        火焰沿顺风方向蔓延最快（蔓延速度×1.5），
        侧风方向中速（×0.7），逆风方向几乎不蔓延（×0.2）。
        风停后，火焰向四周均匀蔓延。
        在Godot中，风向从GameState.wind向量读取，
        火焰的蔓延方向由该向量驱动。

    【湿度影响】
        燃料的moisture参数决定其可燃性：
        moisture>30%：不可燃，火焰无法在其上蔓延
        moisture 10-30%：低可燃性，蔓延速度×0.4，产生大量烟雾
        moisture<10%：高可燃性，蔓延速度×1.0
        moisture<5%：极可燃，蔓延速度×1.5（如干燥草地）

    【可燃物密度】
        连续的高密度可燃物（草地、森林地面枯叶）导致火势迅速失控。
        稀疏的可燃物（单独的树木）火势较慢。
        在Godot中，每个可燃物体挂载FlammableComponent，
        火焰通过Area3D检测周围的可燃物并尝试点燃。

    【地形影响】
        火向上坡蔓延更快（热空气上升，预热上方燃料），
        蔓延速度随坡度增加：每10°坡度+15%速度。
        向下坡蔓延较慢：每10°坡度-10%速度。

    【自然触发】
        闪电在雷暴中有概率（约5%）击中树木或草地引发山火。
        Godot中由WeatherSystem在雷暴天气时随机判定。

    Godot实现：
        ```gdscript
        # FlameSpread.gd
        func try_spread_to(target: Node3D) -> bool:
            if not target.has_method("is_flammable"): return false
            var moisture = target.get_moisture()
            if moisture > 0.3: return false
            var wind_factor = _calculate_wind_factor(target)
            var moisture_factor = 1.0 - moisture * 3.0
            var spread_prob = wind_factor * moisture_factor * 0.8
            return randf() < spread_prob
        ```

6.3 火对AHEI的影响

    火对AHEI的影响按距离分为多个等级。烧伤的详细分级和治疗见文档2第八章8.8节，
    此处仅描述火与AHEI的物理交互规则。

    【温度-距离关系】
        AHEI与火焰的距离决定了其受到的热辐射强度：

    | 距离 | 热辐射强度 | 对AHEI的影响 |
    |------|----------|------------|
    | 直接接触火焰 | 极高 | 持续烧伤（三级烧伤），health快速扣减，皮肤留下永久疤痕 |
    | <0.5米 | 高 | 二级烧伤，health持续扣减，本能驱动立即后退 |
    | 0.5-1.5米 | 中 | 一级烧伤，皮肤灼痛，水分加速流失 |
    | 1.5-3米 | 低 | 温暖舒适（寒冷天气有益），体温缓慢回升 |
    | 3-5米 | 微弱 | 轻微暖意 |
    | >5米 | 无 | 仅视觉感知 |

    【体温调节】
        在寒冷环境中，火是AHEI维持体温的关键热源。
        距离火焰3米以内时，体温回升速度+50%。
        在暴风雪或严寒中，火可能是AHEI生存的唯一保障。

    【行为驱动】
        寒冷环境中的AHEI会本能地靠近火源。
        但如果火焰太大（山火），恐惧系统会覆盖取暖需求，
        驱动AHEI逃离火场。

6.4 火对物体的影响

    火不仅是伤害源，更是AHEI最重要的“天然加工工具”。
    以下所有效果均由Python端的ChemistryEngine判定，
    Godot端执行3D表现。

    【食物加工】
        生肉放置于火焰1米范围内：持续加热30-60秒→变为熟肉。
        熟肉相比生肉：能量值+15%，无寄生虫风险，消化速度+20%。
        如果加热时间过长（>3分钟）→烧焦，能量值-50%，有苦味。
        这是AHEI在学会用火后最早发现的烹饪方式。

    【木材→木炭】
        木材在缺氧条件下加热（用泥土覆盖篝火堆）→变为木炭。
        木炭的燃烧温度（可达1300°C）远超普通木材（约800°C），
        是冶铜和冶铁的关键燃料。
        AHEI可能偶然发现：一场雨后，未完全燃烧的篝火残余物
       （木炭）比普通木材更耐烧、更炽热。

    【黏土→陶器】
        黏土制品放在火焰中烧制约30分钟→变为陶器。
        烧制温度决定陶器品质：
            600-800°C：粗陶（多孔、透水）
            800-1000°C：精陶（致密、防水）
            1000-1200°C：硬陶（极坚硬）
        这是AHEI从“用火取暖”到“用火制作永久容器”的关键技术跃迁。

    【金属加热→锻造】
        金属锭在火焰中加热至红热状态（不发熔化），
        取出后在铁砧上锤打→金属变形、排出杂质、致密组织。
        这是从“铸造”到“锻打”的工艺进步。

    【水→开水】
        水在火焰上加热至沸腾→变为开水。
        开水可以杀菌（降低饮用后感染疾病的概率），
        也可以提取某些植物中的药物成分。
        AHEI可能偶然发现：喝烧开的水后生病概率降低。

6.5 火的熄灭条件

    火焰在以下条件下自动熄灭：
        - 被水浇灭（雨水、河水、水袋倒水）
        - 被沙子/泥土覆盖（隔绝氧气）
        - 被拍打（用树枝或衣物扑打，仅对小火有效）
        - 缺氧环境（密闭空间、洞穴深处氧气不足）
        - 燃料耗尽（可燃物燃尽，火焰自然熄灭）
        - 极端强风（风速>25m/s，火焰被吹灭）

6.6 Godot实现：火焰粒子系统与热传导

    火焰表现：
        - 使用GPUParticles3D表现火焰粒子（橙黄色发光粒子）
        - 粒子系统的emission_rate与火的强度成正比
        - 烟雾使用第二个GPUParticles3D（灰色粒子，上升+扩散）

    热传导检测：
        - 火焰周围挂载一个HeatZone（Area3D），半径3米
        - AHEI进入HeatZone时，体温系统自动计算热辐射吸收
        - 可燃物在HeatZone内时，moisture参数逐渐下降，
          降至可燃阈值以下时可能被点燃

    火焰蔓延算法：
        ```gdscript
        func check_spread_to_neighbors():
            for flammable in get_nearby_flammables():
                var distance = global_position.distance_to(flammable.global_position)
                var wind_factor = _get_wind_factor(flammable)
                var moisture = flammable.moisture
                if moisture < 0.3 and randf() < spread_probability * wind_factor / (distance * distance):
                    flammable.ignite()
        ```

7.2 光对AHEI视野的影响

    在完全黑暗的洞穴中，AHEI的视觉射线距离仅1-2米。
    光源的存在直接决定了AHEI在黑暗中的有效视觉范围。
    
    具体规则：
        - 光源半径 = AHEI在该光源范围内的有效视觉距离
        - 多个光源叠加：光照半径不线性叠加，
          取最大值+副光源半径×20%加成
        - 光源颜色影响视觉：火把偏暖（红橙色），
          发光蘑菇偏冷（蓝绿色），AHEI可通过颜色判断光源类型
        - 光源在水下：光照半径减半，光色偏蓝绿

    详见文档3第二章（视觉系统）和文档11第一章（光学视野系统）。

7.3 光的社会与文化影响

    光不仅是物理工具，更是AHEI社会生活的核心元素：
    
        - 篝火是部落夜间社交的中心——AHEI围坐在篝火旁进行篝火故事、
          分享食物、传递知识
        - AI教师可在篝火旁进行故事化教学
          （详见文档9第十二章）
        - 火把是探险者深入洞穴的必备工具，
          拥有火把制造能力的个体在部落中地位更高
        - 发光蘑菇可能被采集并移植到巢穴中作为永久照明，
          这要求AHEI掌握蘑菇的生长条件并刻意维护
        - 光源的掌握程度是文明等级的重要标志：
          从“只能依赖篝火”到“制造火把”到“发明油灯”，
          每一步都代表着AHEI对黑暗环境的征服

7.4 Godot实现：光照参数配置

    - 火把/篝火/油灯/蜡烛：使用PointLight3D节点 + 对应材质的火焰Mesh
    - 发光蘑菇：使用自发光材质（emission_enabled=true）+ PointLight3D（低能量，蓝绿色）
    - 月光：通过WorldEnvironment的ambient_light_energy调节
    - 太阳：使用DirectionalLight3D，详见文档5第四章
